# EventNexus - Responsive Event Management Landing Page

EventNexus is a modern and responsive event management landing page built using React and Tailwind CSS.

The project allows users to explore upcoming events, browse event categories, and understand the key features of the EventNexus platform.

## 🚀 Features

- Responsive navigation bar
- Hero section with call-to-action buttons
- Featured events section
- Event categories section
- Why EventNexus section
- Responsive design for mobile, tablet, and desktop
- Interactive hover effects
- Lucide React icons
- Modern gradient and glassmorphism UI elements
- Smooth scrolling navigation

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- Vite
- Lucide React
- JavaScript
- HTML5
